Mantrana provides an AI‑driven planning platform that helps developers and product teams quickly generate detailed implementation plans for software projects. Users describe their idea, and Mantrana’s specialist AI jurors produce a structured brief, identify risks, suggest architecture, and outline steps, with options for MVP to enterprise‑level depth. The service offers a remote MCP server for agents, pricing tiers from $1.50 per round, and integrates with tools like Claude Code, OpenCode, Cursor, and Replit, enabling automated planning and review within development workflows.

**Areas:** AI · Planning · Development · MCP · Automation

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Mantrana: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
